Historia de Fog Computing

¿Cómo surgió?

La idea surgió como una evolución de Cloud Computing y de la necesidad de procesar cantidades cada vez mayores de datos producidos por dispositivos IoT.

- Cloud Computing: Década de 2000.
Durante los años 2000 se popularizó la computación en la nube. Empresas y usuarios comenzaron a utilizar servidores remotos para:

  • Almacenar información.
  • Ejecutar aplicaciones.
  • Procesar grandes cantidades de datos.
  • Acceder a recursos informáticos por Internet.

    • El problema era que todo dependía de comunicarse con centros de datos remotos. Expansión del Internet de las Cosas 2010 aproximadamente Con la expansión del Internet of Things (IoT) aparecieron enormes cantidades de dispositivos conectados: sensores; cámaras; automóviles; dispositivos médicos; máquinas industriales; teléfonos; sistemas de seguridad. Estos dispositivos comenzaron a generar cantidades enormes de datos. Enviar absolutamente todos esos datos a la nube podía producir: mayor latencia; congestión de red; mayor consumo de ancho de banda; problemas cuando la conexión a Internet era inestable.

    - Aparición del concepto Fog Computing: El término Fog Computing fue popularizado por Cisco alrededor de 2012–2014. La idea era colocar recursos de computación entre los dispositivos finales y la nube. El nombre fog (niebla) hace referencia a que la computación se extiende desde la "nube" hacia abajo, acercándose al usuario y a los dispositivos. Cisco presentó Fog Computing como una arquitectura especialmente útil para IoT.

    - Desarrollo durante la década de 2010: El concepto comenzó a estudiarse ampliamente en universidades, empresas y organismos de estandarización. Se desarrollaron arquitecturas que combinaban: Cloud + Fog + Edge + IoT También aparecieron tecnologías relacionadas como:

  • Edge Computing.
  • Mobile Edge Computing.
  • Cloudlets.
  • Redes 5G.
  • Procesamiento distribuido.
